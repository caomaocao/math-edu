**上午：设计。** grilling 九项决策逐条拍板——邀请码准入（预生成 10 个）、纯短信无密码
（整块密码代码不存在）、180 天滑动会话、彻底 1:1 不建孩子表、进度不透明 jsonb 整包

`AUTH_MODE` 开关（缺省 off 本地零依赖）、验证态入 Postgres 两张小表（不上 Redis）、
阿里云资源全套复用。spec + 8 张票落 `.scratch/accounts/`。

**下午：并行实现。** 分波推进：01 骨架由主线自做、垄断全部共享文件改动 → 02（认证 API）

08（邀请码脚本 + 文档）。每张后端票 curl 对真库真验，前端合并函数 48 个新 node 测试，
全套 657 绿。两轴 code-review（家规轴 + 规格轴）揪出 4 处修掉——最值的一条：sendBeacon
只会发 POST 而端点只挂了 PUT，pagehide 兜底生而即死。

**晚上：上线换门。** ECS 开 `AUTH_MODE=on`、套着 Basic 双门自测、真手机邀请码注册登录、
摘 nginx `auth_basic`——公网守门从「一个口令」换成「手机号 + 短信 + 邀请码准入」，
孩子的星星从此跟着账号跨设备走。
