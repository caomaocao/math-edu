# 课程设计约定 —— 开新章先读这个

给未来某个要做第4讲（制造错觉、故事推理、认识钱币……）的会话读的**课程设计层**约定：
一章课该长什么样。工程步骤（挂载、双语接线、舞台、实体图的接法）在 CLAUDE.md
「How to add a new chapter」，此处一概不重复。

2026-08-02 grilling 的结论。**约束故意从轻**：新章题材差异太大（空间几何 vs 视错觉 vs
钱币），绑得太死会把新章绑残——这是当场拍板的方向，不是没想到。全文三档：
**铁律**（全部是既有红线/家规的收口，本文零新增）、**默认值**（想偏离就在该章 spec
里写一行理由）、**故意不规定**（写明白，免得后人替我们重新纠结一遍）。

## 铁律（只收口，出处在括号里）

一句话版：孩子不认字、不卡关、不丢进度——任何题材下这三件事不许破。

- 零文字依赖，指令全靠语音；屏幕上唯一允许的字是本讲要教的字（CLAUDE.md 童-UI 铁律）。
- 绝不卡关：错了给机会，最后演示答案照样过关拿星；星星记「完成」不记「全对」
  （两章同款的三次机会先例：错1鼓励 → 错2提示 → 错3演示）。
- 凡要孩子开口的题，必有点击兜底——嗓子哑了、麦克风坏了照样玩
  （问答坞备选按钮惯例，防呆工程的既有投入）。
- 进度永不丢：带版本 localStorage，写失败不抛错；「重来」两次确认（CLAUDE.md）。
- 实体走贴纸风实体图 + 渲染单闸，UI 图形保留 emoji（红线测试在管，见 CLAUDE.md「实体图」）。
- 双语同构从第一天起，台词两表齐备；判对规范名恒中文（CLAUDE.md「Bilingual」）。
- 题面用自有美术重绘，绝不扫描书图；教材 PDF 永不出 data/（版权）。
- 画在基准舞台上、装转屏拦罩、触靶尺寸按各章自己的系数推导（docs/adr/0004）。

## 默认值（偏离请在该章 spec 写一行理由）

- **一章一世界**：每章有自己的母题调色板（02 冷灰蓝+水果色，03 天蓝草绿户外色），
  章章换世界对孩子是新鲜感不是负担——认知负担在交互约定层，那层已经统一。
  但色板必须成体系收进该章 `:root` 变量；02 把 `#4c6fff` 硬编码散进各模块是前车之鉴。
- **节奏**：一个环节孩子一次坐下玩得完；大环节拆轮次（03 玩偶方位 A/B 两轮的先例），
  别学 02 猜一猜 17 题连做。不设数字，判断权在每章 grilling。
- **教材对应**：例题 + 练一练 + 书上闯关的题面尽量全覆盖；自创扩展欢迎——放在书面
  内容之后、难度递进、复用既有管线（03 闯关六~八的先例）。
- **反馈仪式**：完成点星 → 音效 + 纸屑；集齐全章大庆祝（烟花/奖杯）。孩子对
  「这个网站」的身份认知大半系在这套仪式上，换题材不换仪式。

## 故意不规定（别替未来的章节做决定）

- **骨架形态**：少而深（02：5 个重 3D 玩法 + 收集册）还是多而浅（03：地图 hub
  14 关 + Boss 收官），按题材现选，两个先例都活着。
- **题量数字**：不设区间。实测仅供体感：03 单环节 3~13 题，02 单玩法 11~17 题。
- **开口比例**：语音问答是前两章的重心，但不规定新章必须以它为主轴——
  错觉、推理类题材自己定。
- **判定路径**：03 走共享 `问答()` + `/api/judge` 兜底，02 纯本地判，两条都在。
  提示一句：共享管线的防呆/超时/双语已磨过一整轮，自建之前想想值不值。
- **特色能力**：3D、摄像头这类每章的「大招」，要不要、用哪个，全由题材说话。
  唯一提醒：动新模型 ID 先查百炼下线标（CLAUDE.md「Key & model configuration」）。
