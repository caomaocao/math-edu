# AGENTS.md — 第4讲 数字推理《数字小火车》

本目录是一讲的自包含前端，规则的**唯一出处是仓库根的 `CLAUDE.md`**，此处只记目录本地的事。

- 结构：`index.html` 入口；`js/主.js` 铁路地图 hub + 面板切换 + 星星 + 庆祝；
  `js/环节表.js` 13 站的注册表；`js/台词表.js` 两语同构台词；`js/环节/<号>.js` 每站一个模块；
  `js/识律.js`（规律识别，纯逻辑）。数词与摆放引擎 2026-08 升入 shared：
  `/shared/js/数词.js`（0~99 三语说法/判定）、`/shared/js/摆放.js`（点加点减+提交的动手
  引擎，本讲的注入面 —— 汽笛🔔提交钮/火车话术/上限12 —— 收在 `js/组件.js` 的 `摆放配`）。
- 基准舞台 `{宽:1280, 高:760}`（`主.js` 里的常数）；触靶换算见 `styles.css` 头注释，
  **别抄第2/3讲的像素数**（各章系数不同）。
- 数量题动手摆（共享 `摆放.js` + 本讲 `摆放配`），数字题开口报数（共享 `问答()` + 共享 `数词.js`）。
- 山楂、橘瓣、装货站的蘑菇 2026-08 升成写实实体（**推翻**旧「颗数就是答案、身份无所谓」约定）：
  跟草莓/苹果/胡萝卜/茄子/钻石/小花一样走实体图渲染单闸——数据.js 里给它们 `实体`+`兜底`，
  共享摆放引擎的 造件 见 `实体` 就自动走 `画实体`（旧的 `.摆件-山楂/橘瓣/蘑菇` CSS 形状随之退役）；
  判对仍只数颗数、不认长相。关卡布景 花坛（花圃站）/山洞 的盒子也换成贴纸图（空土花坛 / 空山洞，
  栽的花、藏的萝卜各是盖在上面的另一层，用 `画实体` 铺满旧盒 cover）。蘑菇站的黄/蓝蘑菇和篮子
  走贴纸图——黄蓝仍是第二条线索、由两张图给色，数字是盖在伞盖上的白牌（篮子非正方，见 tools/裁篮子.py）。
  （素材升级还剩发车站蒸汽火车 / 数字站小火车头两处 CSS 火车暂缓，本轮不动。）
- 数字规范名是**数字串本身**（"6"、"16"）—— 语言中立，不违「判对规范名恒中文」的本意。
- 台词两表同构、每站导出 `实体们`、进度带版本、重来两次确认、双语从第一天 —— 全按 CLAUDE.md。
- 测试：`test/*.test.js` 走 `node --test`（识律/合并/台词两语/实体图覆盖/题面一致性；
  数词与摆放注入面的测试随模块住在 `web/shared/test/`）。
