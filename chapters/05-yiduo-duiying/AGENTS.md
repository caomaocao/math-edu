# AGENTS.md — 第5讲 一多对应《森林营地野餐会》

本目录是一讲的自包含前端，规则的**唯一出处是仓库根的 `CLAUDE.md`**，此处只记目录本地的事。

- 结构：`index.html` 入口；`js/主.js` 营地地图 hub + 面板切换 + 星星 + 庆祝；
  `js/站点表.js` **台账单一出处**（11 站名单 + 星星账 + 题面核准值，改数值只许改这儿）；
  `js/台词表.js` 两语同构台词；`js/进度.js` 带版本进度 + 云同步 `合并()`；
  `js/站/<号>.js` 每站一个模块。
- 基准舞台 `{宽:1280, 高:720}`（`主.js` 里的常数）；触靶换算见 `styles.css` 头注释
  （89 / 49 两档），**别抄第 2/3/4 讲的像素数**（各章系数不同）。
- 星星账与 03/04 不同：**开营站没有星**（spec：站 1~9 + Boss 共 10 颗）。
  `完成()` 对无星站不点星；大庆祝门槛数 `星站们.length`。
- **并行热点约定（票 02 开的，04~08 票照办）**：
  - `index.html` 的 11 个 `面板-<号>` 挂点、`styles.css` 的「站：<号>」分段占位已一次开好，
    后票**只在自己的段里写**，不许追加到文件尾，不改骨架结构（站点表.test.js 咬着三处一致）。
  - 台词：只往 `中台词/英台词` **加自己那一摊**（摊名 = 站号，两表一起加），
    `全部台词()` 自动收，不用改函数体。跨站共用的 报数/摆放 两摊已开好；
    带数字的模板（报数.教 …）等 `/shared/js/数词.js`（票 01）落地后由最先用到的票补。
  - 站内小进度走 `工具.记/取`（落「柜」，跟星星一起存、同步、被重来清）。
  - 离开一层只走 `工具.回地图`（= `层级.退()`），程序化自动返回也一样（后退家规）。
- 地图节点图标优先挑现库已有素材；帐篷/米饭/蛋糕块/篝火 出图前是兜底 emoji
  （走 `画实体SVG` 单闸，出图后自动升级）。每站导出 `实体们`（真没有就 `[]`），
  boot 的预热与覆盖测试同吃这一个接缝。
- 测试：`test/*.test.js` 走 `node --test`（台词两语同构 / 站点表台账一致性）。
  本章还没进 `web/shared/test/没有实体emoji.test.js` 的扫描名单（那名单硬编码到第 4 讲），
  加名单是 shared 侧的事——归收尾票，别在本目录里等它。
